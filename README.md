# Douars & Communes du Maroc - Base de données interactive

Application web interactive sous forme de tableur (style Google Sheets) répertoriant plus de **10 155 douars et communes du Maroc** avec toutes leurs subdivisions administratives (Provinces/Villes, الجماعات, الجماعات القروية, المشيخات, الدواوير).

**Créé par :** Latifa Mechkirrou  
**Created by :** Latifa Mechkirrou

---

### 🚀 Fonctionnalités :
- 📊 **Interface Google Sheets** épurée, rapide et fluide.
- 🔍 **Recherche globale instantanée** avec surlignage dynamique en jaune (`#fef08a`).
- 🔽 **Filtres par en-tête de colonne** (recherche par colonne, tri A-Z / Z-A, sélection multiple).
- 🌓 **Mode Sombre & Mode Clair** avec mémorisation des préférences.
- 📥 **Export CSV** instantané des données filtrées.
- ⚡ **100% Client-Side** sans serveur, temps de réponse quasi nul (<5ms).
